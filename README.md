# איתור – בית יתיר

אתר חיפוש לפי מספר איתור, שם משפחה או טלפון, עם ניווט ב-Waze וב-Google Maps וחיוג ישיר.
הכניסה בסיסמה קהילתית; הסיסמה נשמרת בכל מכשיר לחודשיים.

## איך זה עובד
- כל 15 דקות תהליך ב-GitHub Actions (`.github/workflows/site.yml`) מוריד את מפת My Maps ואת לשונית "טלפונים" בגיליון.
- `scripts/build_data.py` שומר **רק** את השכבות שב-`LAYERS` (שם, איתור, אשכול, מיקום) ואת הטלפונים, ומצפין הכול בסיסמה (AES-GCM).
- האתר מפרסם רק את הקובץ המוצפן. במאגר עצמו לא נשמר שום נתון – רק טביעת אצבע (`.state/data.sha256`) לזיהוי שינויים.
- מזהה המפה, מזהה הגיליון והסיסמה שמורים כ-Secrets ואינם מופיעים בקוד.

## סריקת אשכולות צח"י
- גבולות וצבעי האשכולות נלקחים מהמצולעים "אשכול N" במפה. רשומה בלי מספר אשכול בתיאור משויכת לפי המיקום שלה.
- הסימונים "נסרק" וההערות נשמרים בשרת Apps Script (`apps-script/Code.gs`) בחשבון גוגל של בנימין, ומשותפים לכל המכשירים.
- כל סימון נמחק אוטומטית 24 שעות אחרי השינוי האחרון שלו. כפתור "ניקוי האשכול" מוחק מיד, לכולם.
- כתובת השרת שמורה כ-Secret בשם `SCAN_API` ונכנסת רק לקובץ המוצפן.
- השרת מאמת כל בקשה ב-`TOKEN` = SHA-256 של הסיסמה (אחרי נרמול: בלי רווחים, אותיות סופיות כרגילות) + `|yatir-scan`.

## פעולות שימושיות
- **עדכון מיידי:** Actions ← "עדכון מהמפה ופרסום האתר" ← Run workflow.
- **החלפת סיסמה:** Settings ← Secrets and variables ← Actions ← `SITE_PASSWORD`, ואז Run workflow. כל המכשירים יתבקשו להזין את הסיסמה החדשה. **צריך לעדכן גם את `TOKEN` בשרת הסריקות** ולפרוס גרסה חדשה (Deploy ← Manage deployments ← עריכה ← New version).
- **הוספת שכבה לחיפוש:** להוסיף את שמה המדויק ל-`LAYERS` בקובץ ה-workflow, מופרד ב-`|`.
